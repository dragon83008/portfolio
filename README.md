# 段小龙个人作品集

React + Vite 作品集与本地作品管理端。首页采用极简纵向作品栈；点击分类封面查看项目列表，点击项目后聚焦该项目的封面与完整素材。

## 运行

```bash
npm install
npm run dev
```

也可双击项目根目录的 `启动作品集.cmd`。保持启动窗口打开，关闭窗口即停止服务。

- 作品集：`http://127.0.0.1:5174/`
- 管理端：`http://127.0.0.1:5174/admin`

服务只监听本机 `127.0.0.1`，手机目前不能远程访问；管理界面已适配窄屏，便于以后扩展。

## 管理作品

1. 选分类，新增或选择作品，修改名称、署名和公开权限。分类封面、项目封面可以分别更换；上传图片或视频后，可点击缩略图查看大图或播放视频。
2. 用上下箭头调整项目或素材顺序，电脑上也可以拖动项目。分类封面可独立更换。
3. 点击「保存草稿」，再点击「预览草稿」检查布局；满意后点击「发布全部更改」。未上传素材的项目继续留在草稿，不妨碍其他项目发布；正在重做的已发布项目会保留旧版，直到新版完成。
4. 五张首页 AI 封面已作为候选存入草稿。点击「预览首页封面」只查看首页封面，项目仍取已发布版本；确认满意后点击「仅发布首页封面」，其他项目草稿不会发布。生成原图位于 `data/originals/ai-covers/`，网页 WebP 位于 `public/portfolio/covers/`。
5. 点击「删除作品」会立即从本地作品集移除该项目并移入回收站；恢复和永久移除也立即生效，不会顺便发布其他草稿修改。原始上传文件不会被删除。待确认授权的项目允许本地预览，但不会出现在 `/api/public-portfolio` 的公开内容数据中。

### 项目介绍

在选中项目的「项目介绍」处点击「添加分块」，为每块填写标题和正文。标题可选「项目背景」「创作思路」「个人职责」，也可自行填写。箭头调整顺序，垃圾桶删除分块；正文支持换行，留空的分块不展示。每个项目最多 12 块。已有的单段介绍会作为一块继续显示，删除全部分块后不会重新出现。

介绍沿用「保存草稿 → 预览草稿 → 发布全部更改」流程。「仅发布首页封面」只更新五张分类封面，不会发布介绍草稿。没有已填写介绍的项目不会出现介绍按钮。目前真实项目的介绍尚未填写；隔离测试截图中的文字只是测试数据。

支持 JPG、PNG、WebP、MP4、MOV、M4V，单文件上限 1GB。图片自动旋正并生成最长边不超过 2400px 的 WebP；视频生成保留原声的网页 MP4 与封面。RAW/DNG 请先导出成图片。首次启动会从现有 `src/portfolioData.js` 导入 23 个项目，此后以 `data/portfolio.json` 为准。

## 备份与恢复

关闭启动窗口后，将整个 `data/` 文件夹复制到其他磁盘。这里包含作品资料 `portfolio.json`、上传原件 `originals/`、网页副本 `media/`；只下载管理端的「数据备份」JSON **不包含媒体文件**。恢复时关闭服务，将备份的 `data/` 文件夹放回项目根目录，再启动。原有素材仍在 `public/portfolio/`，一起移动网站时也要保留。

上线前请重新审查授权；本地的「发布」仅更新本机作品集，不会自动公开部署。

### GitHub Pages 发布

公开站由本机已发布数据生成，保留图片、视频、项目介绍和前端动效，不包含管理后台、上传原件、微信号或二维码。首次配置 GitHub 仓库后，可运行：

```bash
npm run deploy:github
```

命令会导出全部未删除的已发布项目，并覆盖同步到仓库的 `gh-pages` 分支。以后继续在本地管理端添加、删除或修改作品，先完成本地发布，再运行同一命令即可更新线上网站。

### 公开版预览

管理端的「预览公开版」会从**已发布**数据中只收录标记为「已确认可公开」的项目，并只复制页面实际引用的网页媒体到 `dist-public/`。没有可公开项目的分类不会展示；草稿、待确认项目、上传原件、管理后台和未获公开许可的联系方式均不进入预览。此操作不会上传到互联网。决定托管平台并完成账号设置后，再接入真正的发布步骤。

## 当前内容

- 商业广告、品牌设计、摄影作品、AI 设计、短视频五类作品。
- 当前本地已发布且未删除的项目按管理端状态展示；图片、视频与多页分镜可在同一项目内按顺序浏览。
- 滚轮、键盘、分页点与手机手势切换首页分类。
- 分类页按后台顺序纵向展示大幅项目封面，左侧标题随视口中央的项目平滑切换。点击后该项目放大，其他项目淡出，再渐入该项目素材。再次点击放大的封面或信息按钮可查看已发布的分块介绍。素材按原始比例展示；项目内竖图在桌面可双列并排，手机改为单列；点击图片可全屏查看。Esc 会逐级返回大图、介绍、项目、分类及首页。
- 视频进入视口时静音预览，离开视口暂停；点击视频上的放大按钮可打开带播放控件的大画面。首页分类仍支持滚轮、键盘、分页点和手机手势切换。
- 首页聊天图标可打开邮箱与微信联系面板。微信号为 `Dragon-30-0`；黑白二维码位于 `public/portfolio/contact/wechat-qr.png`。图像内没有头像、昵称和地区，原图及桌面/手机网页截图识别出的链接相同。联系信息目前用于本地预览，未来公开部署前需确认展示许可。
- 「关于我」已从简历整理出短介绍和精简经历，在 `?preview=1` 中供确认。正式首页在文案确认前保持此入口未开放，不提供简历下载。
- 首次导入的网页媒体位于 `public/portfolio/`；管理端新增的媒体位于 `data/media/`。`scripts/build-portfolio-assets.ps1` 仅用于重新生成原先的素材，不会改写管理端上传文件。

## 审查资料

- `asset-review.md`：入选、候补、淘汰原因以及公开权限状态。
- `design-qa.md`：视觉修正、交互检查和验证结果。
- `screenshots/`：桌面、手机、作品流、动效与异常状态截图。

商业品牌、客户人物和可识别人物项目目前仅供本地求职预览。公开部署前请先确认 `asset-review.md` 中标记为 `review` 的内容授权。
